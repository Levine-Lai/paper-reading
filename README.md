# Paper Reading

本地浏览器扩展版 PDF 英语学习阅读器：正常用浏览器打开本地 PDF，需要时点击扩展按钮开关淡黄色标注层，自动识别学术词、六级以上词汇和低频形态词。

## 作为浏览器扩展使用

```bash
npm.cmd install
npm.cmd run build
```

然后在 Chrome/Edge 中打开扩展管理页，开启开发者模式，选择“加载已解压的扩展程序”，加载本项目的 `dist` 目录。

在扩展详情页开启“允许访问文件网址”。之后正常打开本地 `file://...pdf`，点击扩展图标即可开关标注层。PDF 通过 file URL 在本机解析，不会上传到服务器。

注意：Chrome/Edge 内置 PDF 查看器本身是浏览器受保护区域，扩展无法直接改它内部的文字层。当前实现是在页面上方叠加一个不拦截鼠标的标注层，因此原本的滚动、选中文字和右键菜单仍由浏览器处理。若某些浏览器版本把 PDF 滚动完全放在受保护插件内部，标注层可能无法跟随内部滚动；这种情况下需要后续做专门的兼容层或使用扩展自带的 reader fallback。

## 开发模式

```bash
npm.cmd run dev
```

打开终端输出的本地地址后，选择一个 PDF 文件即可调试。源码里的 HTML 不能直接双击运行，构建后的 `dist` 才是扩展入口。

## 当前能力

- 点击扩展按钮开关标注层，不自动跳转新页面。
- 本地词库识别学术词、CET6+ 与低频词。
- 标注层使用 `pointer-events: none`，不影响原 PDF 选中文字。
- 扩展自带 reader fallback 支持手动打开 PDF。

## 个人数据同步

生词库和移除词默认存放在浏览器的 `chrome.storage.local`，不会自动出现在 Git 仓库里。

如果要在多台电脑间用 Git 同步：

1. 打开插件弹窗里的 `生词库`。
2. 点击 `导出同步 JSON`。
3. 把下载的文件放到 `user-data/paper-reading-sync.json`。
4. 提交到 Git。
5. 另一台电脑拉取后，在 `生词库` 中点击 `导入同步 JSON`。
